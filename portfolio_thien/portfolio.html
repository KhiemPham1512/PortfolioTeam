01 Giới thiệu bản thân

Thông tin cá nhân & Định hướng chuyên môn

Mình là Đinh Thanh Thiên (sinh ngày 02/10/2006), cựu học sinh Trường THPT Lê Quý Đôn (Biên Hòa, Đồng Nai) và hiện đang theo học ngành Công nghệ Thông tin kết hợp Smart Logistics tại Trường Đại học Giao thông Vận tải TP.HCM (UTH).

Ngoài giờ học trên giảng đường, việc từng trải nghiệm chạy giao hàng công nghệ bán thời gian tại TP.HCM giúp mình quan sát trực tiếp cách vận hành đơn hàng chặng cuối (last-mile delivery), cách tính quãng đường, thời gian giao dự kiến (ETA) và cước phí. Từ đó, mình luôn cố gắng biến các kiến thức lập trình Python, SQL, REST API và AI thành sản phẩm giải quyết bài toán thực tế.

⚙️ Phát triển Backend & REST API

Xây dựng API với Python (FastAPI, Flask), thiết kế CSDL chuẩn hóa và viết tài liệu OpenAPI.

📦 Công nghệ Logistics thông minh

Mô hình hóa bài toán tính trọng lượng quy đổi (DIM Weight), phân vùng cước phí B2B và chuỗi cung ứng.

🧠 Ứng dụng Machine Learning / Deep Learning

Huấn luyện mô hình dự báo chuỗi thời gian, phân loại hình ảnh (CNN) và phân tích cảm xúc văn bản (NLP).
